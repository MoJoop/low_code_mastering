## Contexte

Les écrans du projet P2 sont statiques. Il est temps de leur donner une base
de données réelle, avec de vraies relations entre les objets métier de votre
application.

## Objectifs

- Concevoir un modèle conceptuel de données (entités, attributs, cardinalités)
  puis le passer au modèle relationnel.
- Implémenter ce modèle dans Xano et exposer les premiers endpoints API.
- Brancher WeWeb sur ces endpoints : lister, créer, mettre à jour des données.
- Construire un onboarding fluide et une page d'accueil personnalisée selon
  les données de l'utilisateur connecté.

## Ce qui sera évalué

La soutenance blanche porte sur la justification des cardinalités choisies et
sur votre capacité à retracer un appel API du clic utilisateur jusqu'à la
réponse de la base de données.
